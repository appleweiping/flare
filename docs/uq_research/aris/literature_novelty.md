## 2. Claims actually being tested

1. **Rare-class lifetime retention:** retain the true label at all scheduled looks with class-conditional coverage, allowing safe abstention/first-singleton stopping. Closest exact mechanism: Habib & Shihab, path maximum plus Mondrian groups. Delta: no generic method delta established; astronomy behavior and efficiency remain empirical questions.
2. **Known-class anomaly protection:** reject the known-taxonomy union only when every class is implausible, using the maximum of valid class p-values. Closest logic: standard union-null/intersection-union testing, existing project personal-transfer design, and open-set conformal work. Delta: potentially a useful empirical diagnosis of the power cost of protecting scarce known classes, not a new max-p theorem.
3. **Cost-constrained continuation:** learn, using independent training objects, which ambiguous prefixes merit another observation. Closest: COINS/Vopt-COINS, cost-based early time-series decision methods, and active feature acquisition. Delta: a measurable improvement in rare-transient scientific utility at equal information and cost; generic “learn when to wait” is established.
4. **Joint scientific objective:** prevent a true rare transient being confidently assigned a common label or falsely called anomalous while spending limited resources. Closest: cost-sensitive Mondrian abstention benchmarks plus lifetime/set-decision frameworks. Delta: a deployment-faithful, class-sensitive astronomy finding, if it survives matched baselines and new-population evaluation.

The original evidence that motivates this is concrete: globally certified confidence policies selected 19 SLSN, 18 incorrectly, and pooled trajectory alarms flagged 15/58 known TDEs despite 0.841% aggregate FAR. These are observations in the already-inspected FLARE development study. They are not fresh validation and are not by themselves proof of a new general minority-risk phenomenon.

## 4. Exact validity and feasibility consequences

For fixed class score functions and a fixed scheduled trajectory, let

`M_i,c = max_h s_h(X_i,h,c)` on calibration objects with true class c,

`m_t,c = max_{h<=t} s_h(X_test,h,c)`, and

`p_t,c = (1 + sum_{i:Y_i=c} 1{M_i,c >= m_t,c})/(n_c+1)`.

The running score is bounded by the terminal score. Under within-class exchangeability of complete calibration/test trajectories conditional on the fitted scorer, conservative ranks give `P(exists t: p_t,c <= alpha_c | Y=c) <= alpha_c`. Define `Gamma_t={c:p_t,c>alpha_c}`. The sets are nested and retain the true label over the prescribed path at the stated rate. A wrong singleton commitment implies true-label exclusion. This yields a **class-conditional unconditional wrong-commit probability** bound; it does not yield `P(wrong | committed,Y=c)<=alpha_c` or precision among predictions of c. The class-specific acceptance denominator must be reported.

For a common alarm level a, `p_known,t=max_c p_t,c` is valid for the composite known-class null because it dominates the p-value of whichever class is true. An alarm is an empty set at that same level. This is an intersection-union test, not a learned probability of novelty. If classification and anomaly use different score families/levels, their union needs an explicit error budget or a joint calibration argument. A protected abstention/referral is not a certified anomaly discovery.

**The deterministic rank floor is decisive:** `p_t,c >=1/(n_c+1)`. With the rejection convention `p<=alpha`, excluding c requires `n_c>=ceil(1/alpha)-1` (with exact numerical boundary handling). Therefore:

| Target per-class level | Minimum n_c merely to permit exclusion |
|---|---:|
| 0.10 | 9 |
| 0.05 | 19 |
| 0.01 | 99 |
| 0.0025 (four equal Bonferroni looks for lifetime .01) | 399 |

These are rank-resolution floors, **not** sample sizes for high-confidence conditional-on-calibration selective risk certification. The latter is a different and often harder requirement.

If even one class has n_c<99, deterministic max-p can never raise a .01 anomaly alarm on any input. If TDE n_c<19 at class level .05, TDE remains in every set for every object; any singleton can only be TDE. If two classes are unexcludable, no singleton is possible. These facts hold regardless of how informative the next look is. Randomized ranks can bypass deterministic granularity through random rejection, but that does not create scientific information or justify promising useful anomaly power. Pooling classes changes the guarantee and must not be hidden.

**Path-max efficiency has a second cost:** an early noisy score can permanently remove a true label or inflate the class calibration threshold. Additional looks cannot restore a label in a nested intersection. Learned continuation must justify its cost by eliminating *wrong* alternatives and preserving useful decisions, not by implicitly letting excluded labels re-enter. Terminal-only and shorter prespecified path baselines expose this cost.

4. **Prior-art challenger:** before a new method claim, add a class-conditional COINS allocation with a small predeclared two-stage allocation grid; freeze allocation using a training/strategy sample, then calibrate on independent class-specific trajectories. 5. **Measure useful decisions, not just protection:** per true class, report correct automatic commitments / all objects, wrong commitments / all objects, selected error with its actual denominator, protected-but-unresolved fraction, review fraction, and number/time of reveals. Also report set size and lifetime true-label exclusion. Publish a class-balanced utility vs cost curve with explicit loss weights, or show the vector of class outcomes if no scientific weights are agreed. Never assign zero cost to unresolved cases implicitly.
6. **Same-information and same-budget falsifiers:** learned continuation must beat uncertainty-only and non-myopic controls using the same input features and labels, at the same empirical reveal/review quota. Include a permuted-benefit score and fixed last-look policy. A gain solely from larger sets, more waiting, extra features, or a more favorable certification-family size is not evidence for a new policy mechanism.

An adequate positive screening signal is a consistent increase in rare-class correct commitments or rare-class utility at the same reveal/review budget, without materially increasing wrong commitments, relative to the strongest predeclared information-matched baseline. Thresholds and required practical effect should be chosen by the experiment lead before outcomes; there is no universal numerical gain threshold. A negative signal is that protection only becomes permanent abstention, or learned allocation does no better than uncertainty/random allocation. An underpowered signal is distinct: too few rare examples to separate policies must not be called a failure of every rare-class method.

This CPU replay should take minutes once honest role-specific scores exist; a small linear continuation model should remain comfortably below two hours of CPU time. Saved next-look reveals test **which archived evidence to inspect**, not causal utility of requesting unobserved telescope data. A prospective external claim requires real acquisition availability, label timing/selection, and a new temporal population.
