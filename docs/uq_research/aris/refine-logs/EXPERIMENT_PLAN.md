# Rare-class lifetime decisions under archived checkpoint budgets

Frozen before new real-cohort policy outcomes on 2026-11-02. This is an explicitly posthoc development amendment to the existing study, not a new confirmatory protocol. Scientific design: requested GPT-6-Astra; implementation/execution: requested GPT-6.1-Sol. No paper-writing stage is authorized.

## Problem anchor

Prevent silent wrong automatic labels for rare known transient classes across an object's lifetime, and measure the useful decisions and observation consumption that remain under a limited follow-up budget. The 8,922-object development cohort has already informed research choices. Old test and historical anomalies do not become new validation. Existing twenty classifiers and propertrain/calibration/evaluation memberships stay fixed.

## Claims to test

C1 (diagnostic): replacing pooled protection with true-class lifetime protection can change the achievable decision frontier sharply; finite calibration rank resolution may explain most of the loss. Minimum evidence: per-class calibration counts/infinite thresholds, exact per-class wrong-decision counts, automatic correct decisions, candidate size, unresolved rare objects, and strong fixed-deadline controls.

C2 (exploratory utility): a causal continuation policy trained only on propertrain early-stop trajectories may improve correct-decision yield at identical checkpoint-query budgets relative to uncertainty and static allocation. This is a falsifiable hypothesis, not a promised gain. No method/theorem novelty is claimed: Selection-Safe Conformal Early Exit (2610.20773, Appendix C.3/D.1) and COINS (2609.07112) already contain the core statistical and acquisition ideas.

## Block 1: class-sensitive lifetime sets

Use saved four-look probabilities at days 5,10,20,100. Candidate class score is 1-p_t(c). For class c, calibrate max_t(1-p_t(y)) among calibration objects with y=c. The order index is ceil((n_c+1)(1-alpha)); if it exceeds n_c, use positive infinity. Include ties. At a query prefix, intersect the admitted classes through the current look. Return the first singleton as an automatic label; empty or multiple sets abstain. Later information never changes an issued label.

Compare pooled envelope, Mondrian envelope, pooled Bonferroni, Mondrian Bonferroni, terminal Mondrian, and a separate full-alpha fixed-look Mondrian at EACH deadline. The fixed-look baseline has a guarantee only for its prespecified deadline, not for choosing among deadlines after seeing a query. Bonferroni spends alpha/4 per look. Grid alpha=.01,.05,.10,.20; fixed deadlines=5,10,20,100. Every cell is descriptive; no winner chosen from evaluation labels.

Primary metric is wrong automatic labels divided by ALL objects of each TRUE class. Separately report selected error (wrong/selected), correct automatic count, selection fraction, full scheduled-path true-class exclusion, consumed-prefix exclusion, unresolved retained truth, final set sizes, mean decision day among selected, mean consumed day and cumulative nobs among ALL objects. Fixed-deadline unresolved objects pay the deadline, including empty sets; this deliberate diagnostic cost convention is separate from adaptive operational referral.

Guarantee under within-class exchangeability of whole trajectories and frozen score construction: for each class c, P(any wrong automatic label | Y=c)<=alpha, because a wrong singleton implies exclusion of c on the simultaneous trajectory event. This does NOT guarantee P(wrong | selected,Y=c)<=alpha. Pooled calibration gives a mixture statement only. No guarantee for arbitrary cadence or within-class population change. Threshold estimation uncertainty and adaptively reused development data preclude a new empirical 95% certification claim.

Rank-floor diagnostic is mandatory: class exclusion needs n_c>=ceil(1/alpha)-1. TDE calibration sizes are 13,14,11,9,11 across the five folds, so alpha=.01/.05 envelope cannot exclude TDE for ANY object. If multiple classes have infinite thresholds, singleton decisions are impossible. This is a score-independent finite-sample limit of this deterministic construction, not an impossibility theorem for every method.

## Block 2: exact causal checkpoint-query budget

Initial day5 look for every object is common to all methods and charged separately. One token reveals the next scheduled checkpoint for ONE unresolved object. Each outer fold has its own queue and extra budget B_fold=floor(b*N_fold), b in {0,.25,.5,1,2,3}; pooled reports sum those five quotas. This is not one queue spanning different fitted models. At b=.5 the summed quota is 4,460 rather than floor(.5*8,922)=4,461. Policy sees only each object's currently exposed prefix. It cannot inspect future class sets, probabilities, nobs, or evaluation labels to choose an action. After revealing a new look, record its realized nobs. Singletons close with automatic labels, empty nested sets close with referral, final multiple sets close unresolved. All allocation policies use identical closure rules and identical candidate-set construction. This is archived-checkpoint playback; it is not a telescope-intervention causal evaluation and query tokens are not individual photometric observations.

Controls: round-robin waves (lowest current look, deterministic ID tie), seeded uniform-random active object, current probability entropy, current maximum class probability (confidence), current candidate count, and rare-class probability mass (SLSN+TDE). The confidence control was added after independent pre-run review, before any allocation outcomes, to include an easy-to-resolve priority as well as high-ambiguity priorities. Allocation uses pooled and Mondrian envelopes at alpha=.10,.20; the stricter structural cases are fully characterized by Block1. No evaluation-based choice of alpha or protection regime is permitted.

Learned continuation uses propertrain early-stop trajectories only. For every unresolved training prefix before the final look, inspect its later training path to identify the first later singleton/empty referral or terminal look. Target reward is zero unless the first later singleton is correct; otherwise reward is one for the aggregate-utility learner or N_train/(6*n_train,y) for the macro-class learner. This weighting is estimated from propertrain labels only. These early-stop objects influenced classifier early-stopping selection; their scores are not wholly untouched out-of-fold predictions. Continuation closure targets also depend on calibration-label-derived thresholds; only their feature/reward truth rows are restricted to propertrain early-stop objects. Target cost is the number of additional queries to that first closed state, or final look if none. Fit StandardScaler plus Ridge(alpha=1) independently to reward and cost, no tuning. Use all eligible prefixes with each object's total fitting weight one. At inference rank by max(predicted reward,0)/clip(predicted cost,1,3); costs are expected query counts, not peeked future observations. Fit aggregate-output-only, macro-output-only and macro-quality/temporal variants using the existing reliability_features implementation; append current look index and the same log1p(horizon) basis to every variant because the remaining schedule is always known. Quality/temporal adds only log1p(nobs), previous probability L1 change and previous argmax label switch beyond those shared features. The shared time basis was added during independent review before allocation outcomes. Feature labels are probability argmax consistently in fitting and inference, because the scheduler exposes probabilities rather than separate hierarchical labels; final commitments still use singleton-set labels. Each score is a ranking heuristic, not a calibrated utility probability. If a training fold has no positive reward, return a constant-zero reward model with deterministic ties and record this rather than invent a fitted gain.

Save complete token action ledger, all-object final look/status/prediction, and consumed/unused token counts. Report correct automatic counts and macro class correct-decision rates, wrong-decision rates, candidate utility, and realized nobs cost. Random seeds 0,1,2 assess algorithmic randomness only, not independent dataset uncertainty. No scheduler can overcome a structurally always-included class; a negative utility result ends this mechanism's efficacy claim.
