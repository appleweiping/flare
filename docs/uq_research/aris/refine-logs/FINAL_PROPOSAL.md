# Research implementation proposal: class protection and resource frontiers

This is a working research specification, not paper prose. Scientific lead is requested GPT-6-Astra; implementation and experiment execution use requested GPT-6.1-Sol. Exact backend model telemetry is not exposed by the host. Same-family reviews remain provisional.

## Problem anchor

Prevent silent wrong automatic labels for rare known transient classes across an object's lifetime, and measure the useful decisions and observation consumption that remain under a limited follow-up budget. The 8,922-object development cohort has already informed research choices. Old test and historical anomalies do not become new validation. Existing twenty classifiers and propertrain/calibration/evaluation memberships stay fixed.

## Method thesis and scope

Use established class-conditional simultaneous prediction sets as an explicit protection constraint; measure which candidate commitments and unresolved cases remain at fixed deadlines and under exact archived-checkpoint query budgets. Train only a small reward/cost continuation ranker on propertrain early-stop trajectories. Keep the classifier fixed. The scientific contribution under investigation is an astronomy decision/resource finding, not a new conformal construction.

The main candidate is L1 (finite-resolution and rare-decision frontier) with L3 (incremental resolution utility) as its narrow supporting experiment. Primary sources already contain path maxima, Mondrian extension, arbitrary label-free stopping and utility-aware acquisition: Habib & Shihab 2610.20773 and Li et al. COINS 2609.07112. Cost-sensitive minority-protection findings also have direct neighbors. All eight generated alternatives and their feasibility/novelty risks remain in ../literature_novelty.md; they are not silently eliminated.

## Implementation

1. Load exact saved calibration/evaluation probabilities and independent dataset labels; verify matching propertrain roles and object IDs. Compute finite-sample envelope or Bonferroni thresholds using calibration trajectories as whole units.
2. Keep all class candidates whose prefix scores are admitted; an empty set is a referral, not proof of novelty. A singleton is a candidate commitment. The pathwise guarantee bounds wrong commitment per ALL members of a true class, not precision among emitted labels or error conditional on selection.
3. For resource playback expose day5 to everyone. Charge one token to reveal one object's next prespecified checkpoint. Close singleton, empty, or final-look objects. Allocation sees prefix data only, with future nobs unavailable until the action is taken.
4. Compare random/static/uncertainty/rarity heuristics with three small Ridge reward/cost rankers. Train on propertrain early-stop trajectories, with common-output, class-balanced-output and class-balanced-quality feature variants. Report all frozen cells, not an evaluation-chosen winner.

No new backbone, foundation model, remote GPU, learned score ensemble, acquisition-causal model, or production default is introduced. Those additions do not address the present finite-count and decision-definition bottlenecks without new evidence. Existing PEAR/TGLRec concepts motivate separately listed prior/neighbor candidates; they are not name-dropped as solved improvements.

## Minimum evidence and stop rule

C1 requires a complete per-class rank/decision/set/resource table plus separate fixed-look Mondrian at every deadline. C2 requires the same protection, features and query quota with full action logs, classwise correct/wrong outcomes and random-seed variation. New efficacy claims fail if the learned policy cannot improve the intended utility relative to the strongest control, or if its apparent gain is more waiting, changed thresholds, extra information, or misplaced denominators.

A correct implemented interface and reproducible negative frontier are deliverables. They do not meet a publication-quality or external-validity stop condition. Full run completion and passing tests are deterministic execution facts. Scientific adequacy is independently reviewed and remains same-family/provisional. No paper-writing handoff occurs.

## Current review and limitation

Independent pre-run Astra review found the core mathematically/code-consistent, required a per-deadline fixed-look control and candidate diagnostics, and reviewed those additions as ready for the exploratory pilot. It scored research readiness 7.25/10 and retained REVISE for publication-facing claims. The complete review is ../review-stage/DESIGN_REVIEW.md. The design does not conceal this verdict.

The first executed pilot already exposes a second distinction: an always-retained scarce class can be the only possible singleton label, generating poor precision even while the true-class unconditional wrong-decision event is controlled. Emitted-label confusion/precision must therefore accompany true-class protection. This is a post-pilot diagnostic, not a change to the original endpoint or a new safety certificate.
